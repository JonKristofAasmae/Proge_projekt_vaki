# Grupp Vaki pildisorteerija Pythonis

Selles repositooriumis asub meie programm, mis võtab sisendiks pildi(d) ja sorteerib need. 
Alaprogramme saab käivitada iseseisvalt ning ka põhiprogrammi kaudu. Sisu järgi sorteerimine toimib NLP (*Natural language processing*) mudeli abil, mis teeb inimkeele masinale mõistetavaks.
